# Value Streams

A Value Stream is the series of steps an organization uses to deliver a continuous flow of value to a customer. In Full SAFe, **Development Value Streams** are funded and tracked at the Portfolio Level.

## Value Stream Types

| Type | Description |
|---|---|
| **Operational Value Stream** | Steps to provide goods/services to end customers |
| **Development Value Stream** | Steps to develop the systems that support operational value streams |

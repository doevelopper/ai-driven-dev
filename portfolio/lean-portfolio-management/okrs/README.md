# Portfolio OKRs

Portfolio-level OKRs translate Strategic Themes into measurable outcomes. They cascade down to Solution Trains, ARTs, and Teams.

## OKR Cadence

| Period | When |
|---|---|
| Annual OKRs | Set at start of fiscal year |
| Quarterly OKRs | Reviewed and refined each quarter |
| PI-level OKRs | Derived at ART and team level each PI |

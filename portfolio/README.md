# Portfolio Level

The Portfolio Level connects business strategy to execution through Lean Portfolio Management (LPM). It oversees one or more Development Value Streams and ensures strategic alignment, flow, and governance.

## Responsibilities

- Define and communicate **Strategic Themes**
- Maintain and prioritize the **Portfolio Backlog** (Epics)
- Fund value streams via **Participatory Budgeting** and guardrails
- Track outcomes through **OKRs** and flow metrics
- Provide **Enterprise Architecture** direction

## Key Roles

| Role | Responsibility |
|---|---|
| Business Owner | Value accountability, funding decisions |
| Enterprise Architect | Cross-solution architectural runway |
| Epic Owner | Epic definition, business case, Kanban progress |
| LACE (Lean-Agile Center of Excellence) | Drive and sustain SAFe adoption |
| LPM Team (VMO) | Portfolio flow, metrics, governance |

## Key Events

| Event | Cadence | Purpose |
|---|---|---|
| Strategic Portfolio Review | Quarterly | Align portfolio with strategy |
| Portfolio Sync | Bi-weekly | Review epic flow and impediments |
| Participatory Budgeting | Semi-annually | Allocate budget to value streams |

## Sub-folders

| Folder | Content |
|---|---|
| `strategic-themes/` | Enterprise strategic goals linked to OKRs |
| `backlog/` | Portfolio Backlog — Epics and Enablers |
| `lean-portfolio-management/` | Value streams, guardrails, OKRs |
| `enterprise-architecture/` | Architectural runway, NFRs, tech strategy |

## Flow Metrics (Portfolio)

- Epic flow velocity
- Portfolio WIP
- Time to market (epic cycle time)
- Business value delivered

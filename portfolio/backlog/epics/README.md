# Epics

This folder contains individual Epic definition files. Each epic represents a significant investment hypothesis tracked through the Portfolio Kanban.

## Naming Convention

```
EPIC-<NNN>-<short-slug>.md
```

Example: `EPIC-001-customer-portal-redesign.md`

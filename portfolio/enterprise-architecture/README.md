# Enterprise Architecture

Enterprise Architecture (EA) at the portfolio level provides technology guidance, defines the architectural runway, and ensures the technical strategy enables business agility.

## Role of Enterprise Architect

- Participate in Portfolio Syncs and Strategic Portfolio Reviews
- Define and evolve the **Architectural Runway** across ARTs
- Guide technology choices, NFRs, and platform standards
- Contribute Enabler Epics to the Portfolio Backlog
- Work with System Architects at the ART level

## Architectural Runway

The architectural runway is the existing code, components, and technical infrastructure needed to implement near-term features without excessive re-work.

# OKRs (Objectives and Key Results)

OKRs align strategy to execution at every level of the SAFe hierarchy. They are set at Portfolio, Solution, ART, and Team levels, and cascade to ensure coherence.

## OKR Hierarchy

```
Portfolio OKRs (Annual / Quarterly)
  └── Solution OKRs (per PI)
        └── ART OKRs (per PI)
              └── Team OKRs (per PI, aligned to ART)
```

## OKR Template

```markdown
## Objective: <Inspiring, qualitative, memorable goal>

**Level:** Portfolio | Solution | ART | Team
**Owner:** <!-- Name / Role -->
**Period:** FY2025 Q1 | PI-01 | etc.
**Strategic Theme:** ST-XX (for portfolio OKRs)

| # | Key Result | Baseline | Target | Current | Status |
|---|---|---|---|---|---|
| KR1 | <Measurable outcome> | - | - | - | 🔴 |
| KR2 | <Measurable outcome> | - | - | - | 🔴 |
| KR3 | <Measurable outcome> | - | - | - | 🔴 |

**Status key:** 🔴 Not started | 🟡 At risk | 🟢 On track | ✅ Achieved

**Initiatives linked:** EPIC-XXX / FEAT-XXX / STORY-XXX
**Review cadence:** Weekly check-in | Monthly scoring | Quarterly retrospective
```

## OKR Best Practices

- Objectives are **inspiring and qualitative** — not a task list
- Key Results are **measurable and time-bound**
- Aim for **3–5 Key Results per Objective**
- Set 60–70% of OKRs as stretch goals (not guaranteed)
- Review weekly; score at end of quarter/PI

# Metrics & OKRs

SAFe uses outcome-based metrics at every level to create transparency, drive improvement, and connect execution to strategy.

## Measurement Principles

- Measure **outcomes**, not just outputs
- Use **flow metrics** to identify bottlenecks
- Align metrics to **OKRs** at all levels
- Inspect metrics at PI boundaries (Inspect & Adapt)

## Flow Metrics (SAFe Core)

| Metric | Description | Level |
|---|---|---|
| Flow Velocity | Work items completed per unit time | Team / ART |
| Flow Time | Time from start to done | Team / ART |
| Flow Load | Active work items in progress | Team / ART |
| Flow Distribution | Mix of work types (features, debt, risk, enablers) | ART |
| Flow Efficiency | Active time / total elapsed time | ART |
| Flow Predictability | PI objectives met % | ART |

## Business Metrics

| Metric | Description | Level |
|---|---|---|
| Employee Engagement (eNPS) | Team health and satisfaction | All |
| Customer Satisfaction (CSAT/NPS) | Customer delight | Product / Portfolio |
| Business Value | Value delivered vs. planned | ART / Portfolio |
| Epic Cycle Time | Portfolio epic start-to-done | Portfolio |

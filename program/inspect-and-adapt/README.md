# Inspect & Adapt (I&A)

Inspect & Adapt is a significant event held at the end of every PI. It provides dedicated time for the ART to reflect on what was built and how it was built, and to identify improvement items.

## Three Parts

### Part 1: PI System Demo (30 min)
The ART demonstrates the integrated solution increment to Business Owners and other stakeholders for feedback.

### Part 2: Quantitative Program Measurement (30 min)
The RTE and teams review PI metrics:
- **Program Predictability** (% business value delivered vs. planned)
- **Flow metrics** (velocity, load, time, distribution)
- **Quality metrics** (defect rate, test automation coverage)

Target Program Predictability: **≥ 80%**

### Part 3: Problem-Solving Workshop (60 min)
A structured retrospective and root-cause analysis session:

1. Retrospective — What went well? What didn't?
2. Problem identification — Vote on the most significant problem
3. Root cause analysis — 5-Whys or Fishbone diagram
4. Solutions brainstorming
5. Improvement backlog items → added to next PI backlog

## I&A Output

- **Improvement items** (stories/enablers added to Program Backlog)
- **Updated working agreements**
- **Updated metrics baseline**

# Innovation & Planning (IP) Iteration

The Innovation and Planning Iteration occurs at the end of each PI. It provides a buffer for integration, testing, and planning, as well as time for innovation and improvement.

## Purpose

| Activity | Description |
|---|---|
| **Integration & testing** | Harden the system, resolve final defects, complete CI |
| **PI Planning preparation** | Teams prepare for next PI Planning event |
| **Innovation** | Hackathons, prototypes, tech spikes, learning |
| **Infrastructure & debt** | Pay down technical debt, improve pipelines |
| **Team building** | Activities to strengthen team cohesion |

## Rules

- IP Iteration work should **not** be planned like a regular iteration
- No new features are committed — this is a buffer and innovation period
- Teams self-organize around the activities above
- PI Planning for the next PI typically happens in this week

## IP Iteration Checklist

- [ ] All previous iteration stories closed or carried forward
- [ ] Demo environment stable and clean
- [ ] System Demo completed
- [ ] I&A workshop completed
- [ ] Next PI Planning agenda and materials ready
- [ ] Innovation showcase or hackathon outcome documented

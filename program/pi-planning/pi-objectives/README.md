# PI Objectives

PI Objectives are a summary of the business and technical goals a team (or the ART) intends to accomplish during a Planning Interval. They are created during PI Planning.

## Types of PI Objectives

| Type | Description |
|---|---|
| **Committed** | High-confidence objectives the team commits to |
| **Uncommitted** | Stretch goals — desirable but not guaranteed |
| **Enabler Objectives** | Technical work enabling future features |

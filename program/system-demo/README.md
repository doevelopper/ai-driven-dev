# System Demo

The System Demo is an ART-level event where teams jointly demonstrate the integrated working system built during the iteration or PI. It provides fast feedback from Business Owners and other stakeholders.

## Frequency

- **Every 2 iterations** (mid-PI) — shows integrated increment to date
- **End of PI** — final System Demo before Inspect & Adapt

## Participants

- All Agile Teams
- Release Train Engineer (RTE)
- Product Management
- System Architect
- Business Owners
- Customers (when available)

## System Demo Structure (60–90 min)

| Segment | Duration | Owner |
|---|---|---|
| Intro & context | 5 min | RTE |
| Feature demo by Team A | 10 min | PO Team A |
| Feature demo by Team B | 10 min | PO Team B |
| … (repeat per team) | … | … |
| Integrated system walkthrough | 15 min | Product Management |
| Stakeholder feedback | 15 min | All |
| Summary & next steps | 5 min | RTE |

## Definition of Demo-Ready

A feature is ready for System Demo when:
- All acceptance criteria are met
- Automated tests pass
- Integrated and deployed to the demo environment
- No Sev-1 / Sev-2 defects open

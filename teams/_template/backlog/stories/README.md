# Stories

This folder is for teams that prefer to store story definitions as markdown files alongside the codebase.

> 💡 Most teams manage stories in their issue tracker (GitHub Issues, Jira, Azure DevOps). This folder is optional.

## Naming Convention

```
STORY-<NNN>-<short-slug>.md
```

Example: `STORY-001-user-login-form.md`

# Large Solution Level

The Large Solution Level coordinates the work of multiple Agile Release Trains (ARTs) and Suppliers to build complex solutions that exceed the capacity of a single ART. It is led by the **Solution Train**.

## When to Use

This level is activated when:
- A solution requires **more than one ART**
- **Suppliers or external partners** contribute to delivery
- Complex **system-of-systems** integration is required

## Key Roles

| Role | Responsibility |
|---|---|
| Solution Train Engineer (STE) | Facilitates Solution Train events, removes impediments |
| Solution Management | Defines solution vision, roadmap, and backlog |
| Solution Architect / Engineering | Technical leadership across ARTs |
| Customer | Validates solution fit and provides feedback |
| Supplier | Delivers agreed-upon components or subsystems |

## Key Events

| Event | Cadence | Purpose |
|---|---|---|
| Pre-PI Planning | Before each PI | Align ARTs on solution vision and top capabilities |
| Post-PI Planning | After each PI | Integrate ART PI Objectives into Solution PI Objectives |
| Solution Demo | End of PI | Demonstrate integrated solution increment |
| Inspect & Adapt | End of PI | Reflect and improve at solution-train level |

## Sub-folders

| Folder | Content |
|---|---|
| `solution-train/` | Solution Train charter, roster, vision |
| `backlog/` | Solution Backlog — Capabilities and Enabler Capabilities |
| `solution-intent/` | Fixed and variable solution intent documents |
| `suppliers/` | Supplier agreements, integration interfaces |

## Artifacts

- **Solution Roadmap** — planned capability delivery over time
- **Solution Intent** — describes the intended behavior of the solution
- **Solution PI Objectives** — committed and uncommitted objectives per PI
- **Capabilities** — cross-ART features that deliver solution-level value

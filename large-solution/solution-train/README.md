# Solution Train

The Solution Train is the organizational construct used to build large and complex solutions. It aligns and coordinates the ARTs and Suppliers within a **Development Value Stream**.

## Composition

- 2 or more Agile Release Trains (ARTs)
- External Suppliers (optional)
- Shared System Team (optional)
- Solution Train Engineering (STE, Solution Management, Solution Architect)

# Suppliers

This folder manages external Suppliers and Partner ARTs that contribute components or subsystems to the Solution Train.

## What Is a Supplier?

A Supplier is an external entity (vendor, partner, or internal shared-service team) that delivers defined functionality to the Solution Train under a negotiated interface agreement.

## Supplier Management Principles

- Engage suppliers **early** in PI Planning (Pre-PI Planning)
- Define clear **interface agreements** (APIs, protocols, SLAs)
- Include supplier deliverables in **Solution PI Objectives**
- Run **joint demos** when possible
- Apply **Lean-Agile Procurement** practices

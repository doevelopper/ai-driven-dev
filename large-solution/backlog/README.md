# Solution Backlog

The Solution Backlog holds **Capabilities** and **Enabler Capabilities** that span multiple ARTs and must be coordinated at the Solution Train level.

## Capability vs Feature

| Artifact | Level | Scope |
|---|---|---|
| **Epic** | Portfolio | Cross-ART, multi-PI investment |
| **Capability** | Large Solution | Multi-ART, deliverable within a PI |
| **Feature** | Program (ART) | Single ART, deliverable within a PI |
| **Story** | Team | Single team, deliverable within an iteration |

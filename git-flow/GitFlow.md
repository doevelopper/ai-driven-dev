
| **Branch Name** | **Purpose** | **Creation** | **Merge Procedure** | **Merge Prerequisites** | **Who** | **Role Details** |
|-----------------|-------------|--------------|---------------------|-------------------------|---------------|------------------|
| **Main Branch** | Holds the production-ready code. Always deployable and should remain stable. | Created initially when the repository is set up. | Changes are merged into the main branch from release branches after thorough testing and validation. | All tests must pass, and code reviews must be completed. The release branch must be stable and ready for production. | Release Manager | Ensures the main branch remains stable and production-ready. Oversees the final integration of changes from release branches. |
| **Development Branch** | This is where active development takes place. Serves as the integration branch for new features before they are merged into main. | Created from the main branch. | Changes are merged into the develop branch from feature, bugfix, coverity, and polaris branches. | All tests must pass, and code reviews must be completed. The branch must be stable and free of critical issues. | Development Team Lead | Manages the integration of new features and bug fixes. Ensures the develop branch is stable and ready for the next release. |
| **Feature Branches** | Used for developing new features. | Created from the develop branch. | Merged back into develop once the feature is complete. | The feature must be fully developed, tested, and reviewed. All tests must pass, and code reviews must be completed. | Feature doevelopper | Develops new features. Ensures features are fully functional and tested before merging. |
| **Bugfix Branches** | Used for fixing development defects. | Created from the develop branch. | Merged back into develop once the defect is fixed. | The bug must be fully resolved, tested, and reviewed. All tests must pass, and code reviews must be completed. | Bugfix doevelopper | Fixes development defects. Ensures bugs are resolved and tested before merging. |
| **Release Branches** | Used to prepare for a new release. | Created from the develop branch. | Stabilized before being merged into both main and develop. | The release must be thoroughly tested, and any last-minute bug fixes must be applied. All tests must pass, and code reviews must be completed. The branch must be stable and ready for production. | Release Manager | Prepares the code for release. Ensures the release branch is stable and ready for production. |
| **Coverity Branches** | Used for static code analysis using Coverity to identify and fix potential defects. | Created from the develop branch. | Merged back into the develop branch once the analysis is complete and issues are resolved. | All identified issues must be addressed, and the branch must pass static analysis checks. Code reviews must be completed. | QA Engineer | Conducts static code analysis. Identifies and resolves potential defects before merging. |
| **Polaris Branches** | Used for security and compliance checks using Polaris to ensure code meets security standards and compliance requirements. | Created from the develop branch. | Merged back into the develop branch once the checks are complete and necessary adjustments are made. | All security and compliance issues must be resolved, and the branch must pass all relevant checks. Code reviews must be completed. | Security Engineer | Conducts security and compliance checks. Ensures code meets security standards before merging. |
| **CATO** | Used to ensure that the code meets cybersecurity standards and is authorized to operate at an acceptable level of risk. | Created from the develop branch. | Merged back into the develop branch once the cybersecurity authorization process is complete and any identified risks are mitigated. | All identified cybersecurity risks must be addressed, and the branch must pass all relevant security checks. Code reviews must be completed. | Cybersecurity Officer | Conducts thorough cybersecurity assessments. Ensures the code meets all security standards and is authorized to operate. |
